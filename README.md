# Идея 
Матрешка
Мороженое с русской душой из органических ингридиентов.

# Идея компании
Вкусы мороженого вдохновлены национальными особенностями культур России. Примеры таких вкусов: 
* Медовое мороженое со вкусом чак-чака
* Мороженое - кулич
* Сорбет со вкусом кваса с кусочками ржаного хлеба

Принимая во внимание укрепившийся тренд на здоровый образ жизни и правильное питание, мы решили разрабатывать мороженое из натуральных ингридиентов. Кроме того, еще одним трендом в последнее время становится возрождение русских традиций, поэтому в качестве конкурентного преимущества были выбраны такие необычные вкусы.
