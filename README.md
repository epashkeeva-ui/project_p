## Идея
Real Estate Flipping Analysis

## Описание проекта
Исследование отрасли флиппинга недвижимости: автоматизация поиска недооцененных объектов, расчет стоимости реновации и оценка финансовой модели бизнеса

## Источники данных
1. **Агрегаторы недвижимости (Avito / Циан)**: Сбор цен на объекты в состоянии «под ремонт» и готовое жилье для расчета рыночной вилки
2. **Сервисы готового ремонта**: Сбор тарифов на ремонтные услуги «под ключ» за м² для оценки затрат на контрагентов
3. **Порталы по поиску работы (hh.ru)**: Анализ заработных плат для расчета Total Cost сотрудников (риэлторы, юристы, прорабы)

## Направления анализа
* **Целевая аудитория**: Формирование портрета покупателя и оценка его платежеспособности
* **Экономика**: Расчет чистой маржинальности с учетом затрат на закупку, ремонт и ФОТ
* **Конкуренция**: Определение стратегии выхода на рынок и отличий от текущих игроков
