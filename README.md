## Идея компании
Мороженое Slush 

## Состав группы
Пашкеева Елизавета (github: epashkeeva-ui), Купча Софья (github: Kupchaso), Тосунян Даниэль (github: benariq)

## Описание
Создание производства мороженого в специализированной упаковке для онлайн-доставки. Продажа будет осуществляться на маркетплейсах. 

## Разделение обязанностей
* Пашкеева Елизавета - анализ ценового позиционирования и конкурентов (статистический парсинг сайтов-агрегаторов цен и каталогов ритейлеров)
* Купча Софья - анализ логистики, персонала и складов (использование API карт и парсинг hh.ru, rusprofile)
* Тосунян Даниэль - анализ целевой аудитории, ее опыта, рыночных ниш (динамический парсинг карточек товаров на маркетплейсах)
* Все вместе - анализ рыночных трендов и сезонности (сбор данных через API или экспорт из инструментов анализа поисковых запросов - Yandex Wordstat, Google trends)
