Аналитический проект по парсингу и анализу рынка мороженого в Москве. Цель — определить **самый прибыльный формат и вкус** мороженого с позиции производителя, оценить **логистику и склады** и проанализировать **рынок, конкурентов и поставщиков** для запуска производства.

По итогам анализа в качестве флагманского продукта выбран **сорбет «Малина-Личи»** — позиция с высоким скором (премия по цене × популярность) и хорошим положением в нише.

## Часть 1. Ассортимент и скоринг товаров

> Автор: Даниэль Тосунян

Парсинг полного ассортимента мороженого с двух источников — **ВкусВилл** и **Перекрёсток** — и анализ собранной таблицы для поиска самого прибыльного формата и вкуса.

### Пайплайн парсинга

1. **Сбор HTML** — открытие страниц каталога и выгрузка полного HTML после рендера. Инструменты: `Selenium`, `seleniumbase`, `selenium-stealth`.
2. **Извлечение карточек** — итерация по карточкам товаров, парсинг полей, сохранение в `DataFrame`. Инструменты: `BeautifulSoup`, `pandas`.
3. **Категоризация** — сортировка по типам через regex и список названий; для каждого товара добавлены булевые столбцы категорий (ПП, Необычный вкус, Вафельный стаканчик, Рожок, Сорбет/лёд, Эскимо и др.).

Итоговые поля: `Название`, `Цена`, `Вес`, `Рейтинг`, `Кол-во отзывов`, `Ссылка`, `Цена за 100 г` + булевые признаки категорий.

### Скоринг по нишам

Товары оцениваются внутри своих ниш по двухкомпонентной формуле.

**Иерархия ниш (по приоритету):**

| Уровень | Ниши |
|---|---|
| 1 | ПП · Необычный вкус |
| 2 | Эскимо · Рожок · Вафельный стаканчик · Большая порция · Сорбет/лёд |
| 3 | Пломбир |
| 4 | Стаканчик (не вафельный) |

**Алгоритм:**

1. Находим все ниши, в которые попадает товар.
2. Сортируем их по уровню (1 → 4).
3. Берём топ-2 ниши с высшего уровня.
4. Считаем итог: `score = 0.9 × score₁ + 0.1 × score₂`.

**Формулы:**

```
Премия       = (цена за 100 г) / (медиана цены за 100 г в нише)
Популярность = ln(1 + кол-во отзывов) / ln(1 + медиана кол-ва отзывов в нише)

Score = Премия × Популярность
```

Фильтр `рейтинг ≥ 4.5` применяется отдельно и **не входит** в формулу скоринга.

### Результаты анализа

- Топ-25 кандидатов по обоим источникам (ВкусВилл и Перекрёсток) в координатах «премия по цене × относительная популярность».

### Все ниже визуализировала Купча С.
- Отдельный разбор ниши **сорбетов**: лидер — сорбет «Малина-Личи» (score 1.37 ВкусВилл / 1.57 Перекрёсток).
- Распределение цены за 100 г по всему ассортименту: медиана 175 ₽ (Перекрёсток) и 159 ₽ (ВкусВилл); «Малина-Личи» при 264 ₽ и 224 ₽ соответственно сидит в премиальном сегменте.

## Часть 2. Логистика и склады

> Автор: Софья Купча

Цель — найти оптимальный склад-морозилку с минимальной совокупной стоимостью (аренда + доставка до ближайшего дарксторного хаба).

### Блок 1. Склады-морозилки

- Источник: `moskva.skladoiskatel.ru`
- Инструмент: `BeautifulSoup`
- Результат: **30 складов** с полями `id`, `address`, `price`, `latitude`, `longitude`.

### Блок 2. Склады Озон Фреш

- Источник: API `catalog.api.2gis.com/3.0/items` (ключ 2GIS API)
- Результат: **50 точек** Ozon Fresh с координатами.

### Блок 3. Финальный датафрейм (цена + расстояние)

Цель — для каждого склада-морозилки получить цену и расстояние по дорогам до ближайшего Озон Фреш.

Из-за жёстких лимитов 2GIS Routing API применена двухшаговая оптимизация:

1. Сначала ищем ближайший Озон **по прямой** (формула Haversine) — без запросов к API.
2. Только для этого ближайшего Озона считаем реальное расстояние **по дорогам** через `routing.api.2gis.com/routing/`.

Итог — датафрейм с колонкой `distance_km` для всех 30 складов.

## Часть 3. Анализ рынка

> Автор: Елизавета Пашкеева

### Блок 1. Сезонность спроса

- **Что:** число запросов «сорбет» в Яндекс Wordstat, январь 2018 — май 2026.
- **Как:** коэффициент сезонности = (среднее число запросов в месяц) / (среднее число запросов за год).
- **Источник:** CSV-выгрузка с Яндекс Wordstat.
- **Выводы:**
  1. Число запросов растёт каждый год → отрасль растёт → можно рассчитывать на долгосрочный рост спроса.
  2. Явная сезонность с пиком в июне/июле (тёплая погода).

### Блок 2. Анализ конкурентов

- **Что:** магазины и точки в Яндекс Еде как потенциальные каналы продаж сорбета в доставке.
- **Метод:** `score = r × ln(o)`, где `r` — рейтинг (0–5), `o` — количество отзывов.
- **Как:** динамический парсинг через `Selenium`.
- **Выводы:** перспективны магазины «зелёной зоны» (топ-10 по скору) — крупные сети добавляют доверия новому продукту. Отдельная ниша — Даниловский и Усачёвский рынки.

### Блок 3. Гипотеза про ценообразование

- **Гипотеза:** ЗОЖ в тренде → потребители готовы платить больше за ПП-продукты, и это отражается в цене.
- **Проверка:** корреляция между ценой за грамм и калорийностью на грамм.
- **Как:** динамический парсинг карточек товаров топ-10 магазинов «зелёной зоны» через `Selenium`.
- **Результат:** коэффициент корреляции ≈ **−0.015** → прямой связи нет. Чтобы заработать на ЗОЖ-позиционировании, нужно опираться на бренд, а не на формальную калорийность.

### Блок 4. Анализ поставщиков сырья

- **Цель:** база поставщиков и список сырья для производства сорбета «Малина-Личи» (базовый состав взят с уже продающегося сорбета ВкусВилла).
- **Как:** статический парсинг сайтов поставщиков через `Requests` + `BeautifulSoup`.
- **Фруктовое пюре:** анализировались «Две Морковки», «Ягодный мастер», «Пекр», «Италика». Оптимальный — **Пекр** (низкая цена, есть и личи, и малина).
- **Сахар:** из популярных поставщиков (Сахаропт, Шугар компания, Агросервер) после отсева частников топ-3: ООО «ИНТЕГРАЛ», ООО «МОС ЯРД ИНВЕСТ», ООО «ЭНДОРФИН».
