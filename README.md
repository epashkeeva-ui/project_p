## Описание
Создание производства мороженого в специализированной упаковке для онлайн-доставки. Продажа будет осуществляться на маркетплейсах.

* Пашкеева Елизавета - анализ ценового позиционирования и конкурентов (статический парсинг сайтов-агрегаторов цен и каталогов ритейлеров). анализ рыночных трендов и сезонности (сбор данных через API или экспорт из инструментов анализа поисковых запросов - Yandex Wordstat, Google trends).
